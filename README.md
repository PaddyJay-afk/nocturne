# Nocturne · Sky & Signal

A mobile-ready project landing page for Nocturne.

## GitHub Pages

The site is deployed from the repository root by GitHub Actions. Every push to `main` runs the deployment workflow; it can also be started manually from the Actions tab.

Expected URL: https://paddyjay-afk.github.io/nocturne/

## Project status

This repository currently contains the landing page and publishing workflow. It does not yet contain the Nocturne iOS/AR app source code. The site describes the intended product experience and links to this repository for project updates.
