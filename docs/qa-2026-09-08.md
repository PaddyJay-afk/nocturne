# Nocturne update validation — 8 September 2026

## Changes

- Motion permission is requested directly from the user gesture, with iOS constructor binding, valid compass handling, absolute orientation support, timeout and actionable recovery. Manual calibration remains available when the browser blocks sensors.
- Satellite overlay uses a dedicated worker and CelesTrak's public active catalog. The bundled dated fallback contains 16,510 records. CSV/OMM JSON/TLE import supports broader published catalogs. This is not every known object: inactive objects, debris, classified and untracked objects are not comprehensively covered by the automatic feed.
- At most 12 separated markers, four labels and three selected paths are rendered. Paths use color, number and line pattern, cover -30 to +120 seconds and preserve the user's observation point. Position prediction does not establish visual visibility or object identity.
- Catalog downloads are cached for 12 hours; provider failures back off. A worker scans the full catalog every 15 seconds and updates visible candidates every 750 ms; rendering interpolates positions. Work pauses when disabled or hidden. Epochs older than seven days are excluded.
- Recording failures distinguish actual quota failures from other storage errors. Unsaved captures remain available for an explicit download. IndexedDB supports binary fallback and retry after failed opens. Session deletion is atomic. Pending audio starts are cancelled by Stop all. Other fixes cover camera cleanup, empty binary input, short cycle display and offline cache failure.

## Verification

Production build, TypeScript check and git whitespace check passed. All 58 automated checks passed (36 TypeScript unit checks and 22 integration/render/storage checks). Tests include permission timing, invalid/no sensor readings, listener cleanup, real catalog propagation and search, bounded overlay transfer, stale epochs, three paths, API cache/backoff, storage round trips and failures, atomic deletion, offline behavior and signal cancellation.

Browser interactions covered calibration validation and sliders, permission-unavailable recovery, signal start/stop and parameter application, binary validation and sequence import, session controls, synthetic audio import and playback controls, bookmarks, journal notes and export click, camera-unavailable recovery, satellite catalog loading/search/tap selection and three comparison paths. A final visual check confirmed the compact camera invitation and path legend leave sky space clear, with the observation point preserved. Export file contents and actual audible output were not independently verified.

A temporary development preview module-load failure following concurrent build/test activity resolved after restarting the preview. Final interaction checks used the restarted preview.

Performance measured in the development server VM, not on an iPhone: 2,495,751-byte catalog, approximately 30 KB worker, 655 ms parse, 346 ms initial frame including a 321 ms full scan; subsequent sampled frames approximately 23–25 ms, with bounded output of 80 candidates and three paths. These measurements do not certify mobile frame rate or battery life.

## Remaining validation

Physical iPhone motion permission, compass accuracy, embedded-browser policy, live camera/recording/torch, long recordings, audible output and installed Home Screen offline behavior require device testing. The browser preview has no usable phone sensors. No claim of every function being error-free is made. The native wrapper was not rebuilt or tested.

The source feed may be unavailable; a dated cache/snapshot is shown explicitly and stale predictions are hidden. Public orbital data can drift after maneuvers. Feed documentation: https://celestrak.org/NORAD/documentation/gp-data-formats.php

## 9 September continuation

The previously blocked settings work was completed after writable source access was restored. The app now defaults to a persistent Simple mode and offers Advanced mode from both the signal panel and calibration dialog. Simple mode keeps the preset, volume, light, session-length, location, motion, satellite, label, constellation, and night controls visible; Advanced adds signal-shaping, randomized control intervals, assisted detection, and manual overlay calibration.

Every form setting rendered through the shared range, toggle, and choice controls now has a circled question-mark button with a short effect summary. Custom color, binary sequence/import/source, satellite import/search, and coordinate controls have matching help. Slider interaction areas are 48 px tall with 24 px thumbs and 8 px tracks.

The production build and all 58 automated checks passed after the final source changes. Browser QA verified Simple-mode reduction, Advanced-mode expansion, help-dialog content, saved mode persistence, 48-by-24 px slider geometry, keyboard slider changes, calibration help, satellite catalog loading (16,510 bundled records), NORAD 25544 search, signal start/stop, and actionable camera/motion recovery in an environment without phone hardware. No application console errors were observed; the cloud browser emitted only its own extension metadata error.

Physical iPhone motion, live camera/recording/torch, installed Home Screen offline behavior, and audible output remain device checks because those capabilities are not present in the test browser. See `HANDOFF.md` for the exact checklist.
